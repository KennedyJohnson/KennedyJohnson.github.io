Movie Recommender 2026

A live web app built on my capstone: rate a few movies and get a ranked list of what to watch next. I re-ran the comparison on 33.8M fresh MovieLens ratings and added implicit-feedback ALS. SVDF was still the most accurate at predicting a single star rating, but implicit ALS built ranked lists more than 5x better (nDCG@10 of 0.30 vs 0.055), so the app serves ALS. The models are implemented from scratch in numba and trained locally. A FastAPI service on Render works out each new visitor's taste profile in milliseconds, and the frontend runs on GitHub Pages with TMDB posters.

Comparison of Recommender Algorithms 2024

Not all recommender algorithms are worth their added complexity: some barely beat just suggesting the most popular movies. Using 32M MovieLens ratings split into sparse, moderate, and dense user datasets, we benchmarked collaborative filtering (UBCF, IBCF) against matrix factorization methods (SVD, SVDF, ALS, PMF) on RMSE, MAE, and precision/recall. Only SVDF and PMF consistently beat the popularity baseline across every dataset size, while collaborative filtering needed dense rating data to be competitive at all.
