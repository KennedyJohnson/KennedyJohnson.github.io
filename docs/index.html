Twin Cities Living Quality Map 2026

Choosing where to live means weighing safety, affordability, and opportunity against each other, using information that's public but scattered across a dozen city, county, and federal sources. I built a Python/pytest pipeline that pulls open data from St. Paul, Minneapolis, OpenStreetMap, the U.S. Census, MnDOT, and CDC into a single weighted Health Score per district, surfaced through a Next.js map with address search and historical trend charts, so anyone can compare neighborhoods by what actually matters to them.

Comparison of Recommender Algorithms 2024

Not all recommender algorithms are worth their added complexity: some barely beat just suggesting the most popular movies. Using 32M MovieLens ratings split into sparse, moderate, and dense user datasets, we benchmarked collaborative filtering (UBCF, IBCF) against matrix factorization methods (SVD, SVDF, ALS, PMF) on RMSE, MAE, and precision/recall. Only SVDF and PMF consistently beat the popularity baseline across every dataset size, while collaborative filtering needed dense rating data to be competitive at all.

Heart Failure Survival Analysis 2024

Not every clinical measurement taken for heart failure patients is actually useful for predicting survival: some noisy features were hurting classification more than helping. Using PCA and MDS for dimensionality reduction, then a Gaussian Graphical Model to select the few variables most tied to mortality (ejection fraction and serum creatinine among them), we improved a KNN survival classifier's accuracy from 20% to 85%, pointing to specific measurements clinicians could prioritize when monitoring at-risk patients.
